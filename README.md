# 👑 STATUS KING
1. `npm install`
2. Set env vars (see `.env.example`): MONGO_URI, OWNER, GROUP_LINKS
3. `node index.js` → open http://localhost:3000 → enter number → paste code in WhatsApp > Linked Devices
- Heroku/Railway: deploy repo, add the same env vars (MONGO_URI is required there).
- New command: drop a file in `plugins/` (auto in menu) or add a `case` in `cases.js`.
